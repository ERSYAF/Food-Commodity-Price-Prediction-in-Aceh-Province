LSTM vs GRU

Evaluasi mendalam performa dua model deep learning untuk prediksi harga komoditas pangan Aceh.

🟡
Long Short-Term Memory
LSTM
LSTM menggunakan tiga gerbang (forget, input, output gate) untuk mengontrol aliran informasi. Mampu menangkap dependensi jangka panjang dalam deret waktu, cocok untuk pola harga yang lambat berubah.
Input Shape(None, 30, 3)
Output(None, 3)
Ukuran File~1.5 MB
Sequence30 hari
VS
🟣
Gated Recurrent Unit
LSTM-GRU
GRU menyederhanakan LSTM menjadi dua gerbang (reset & update gate), lebih efisien secara komputasi. Cenderung lebih cepat konvergen dan unggul pada data dengan volatilitas tinggi seperti cabai.
